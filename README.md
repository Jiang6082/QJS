## How to Run

Requires **Node.js 18+**. From the repo folder:

```bash
npm run refresh:v2          # portable two-pass quant scan, reports, and validation
npm run refresh:v2:publish  # same workflow, then commit and push
npm run scan:v2             # alias for the protected refresh
npm run scan:v2:diagnostic  # one pass; does not rebuild or publish reports
npm run scan:all            # protected quant refresh plus the other scanners
```

**Scan modes:** `v1` (known ATS boards) · `v2` (ATS + expanded quant search) · `broad` (ATS + broader US financial-services) · `swe` (2027 software/eng roles) · `all` (full workflow).

### Normal workflow on any machine

```bash
git pull --ff-only
npm run refresh:v2:publish
```

Run the portable workflow from a clean worktree. It records the committed baseline and two complete source passes, rechecks manually tracked postings, rebuilds all quant reports, and validates the README too. Additions must appear in both passes. Closures require successful absence evidence from the role's own source in both passes; failures remain guarded. [Confirmation evidence](data/scan_confirmation.json), [stability history](data/stable_quant_roles.json), and [date history](data/role_date_history.json) travel with the repository; do not copy `.scan-state` between machines. A failed refresh restores the previous reports, and a lock prevents concurrent refreshes.

Publishing stages generated artifacts only, refuses unrelated staged files, validates before committing, and verifies the remote commit. Run `npm run publish` to publish completed reports or retry a failed push. The PowerShell entry point delegates to the same workflow. Run `npm test` for regression checks.
